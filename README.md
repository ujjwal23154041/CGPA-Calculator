# CGPA Calculator (C++)

A simple **CGPA Calculator** built using **C++ and Object-Oriented Programming (OOP)** concepts.  
This program allows students to enter course grades and credit hours, then calculates the final CGPA.

---

## 🚀 Features

- Menu-driven console application
- Uses **classes and objects**
- Grade to grade-point conversion
- Supports multiple courses
- Displays:
  - Total credits
  - Total grade points
  - Final CGPA (up to 2 decimal places)
